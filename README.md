## 📄 Featured Project

### [Thesis PDF Framework](https://github.com/chrisTechn7/thesis-pdf-framework)

An open-source framework for creating academic and technical theses from Markdown using Pandoc and LuaLaTeX.

**Key features:**

- 🇩🇪 🇬🇧 German and English starter documents
- 🎨 Configurable PDF layouts and title pages
- 🧪 Automated regression checks
- 🐳 Optional Docker workflow
- 📚 Extensive documentation and a fictional demonstration project

**My role:** I defined the requirements, directed the implementation, reviewed the generated documents, coordinated testing, and managed the publication process. Much of the Python and Lua implementation was generated with OpenAI Codex under my direction.
